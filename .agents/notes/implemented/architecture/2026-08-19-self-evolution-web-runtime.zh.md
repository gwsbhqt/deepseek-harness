# Agent Note: 自进化 Web 接入独立运行时

Status: implemented

[English](2026-08-19-self-evolution-web-runtime.md) | 中文

## 问题

自进化示例持有一批不能靠同名组合重建的实时状态：已注册的 `self-evolution-main` Agent、宿主外 IPython 内核、动态 Cordis 插件、活动目标和终端回退入口。Web 预设或独立 Web 进程只能暴露第二个 Agent 或持久历史，不能暴露这份活动运行时。

操作者还需要继续使用官方通用 `dsh web` 模式。替换它的 `ds` 命令或端口会把单个实验绑到产品级浏览器入口上。

## 决策

`examples/self-evolution/cordis.yml` 在独立 Agent 组合之后直接挂载 Web Host API 和浏览器客户端插件。API 代理解析已经注册的 `self-evolution-main` Agent，因此 Web 对话、终端回退、IPython、目标和动态插件使用同一进程、同一会话。

通用 `ds` 命令继续在 `127.0.0.1:3080` 运行官方 `dsh web`。单独的 `dse` 命令启动或复用 `self-evolution` rmux 会话，并在 `127.0.0.1:3081` 暴露这份组合。重复执行 `dse` 会复用活动会话。启动失败时，命令会打印最近的运行输出，并且只清理失败的 `self-evolution` rmux 会话。

浏览器提供对话和轨迹视图，Cordis 面板显示并控制当前会话的动态插件，不挂通用设置页或完整 Loader 清单。模型可见的 `cordis_*` 工具保持不变。`plugin-repl` 继续作为终端回退入口。

浏览器第一次打开时可能选中新草稿，而不是唯一的持久会话。手动选择一次现有会话只是浏览器状态，不会创建另一份运行时。隐藏“新建会话”或强制只能选择一个会话不属于本次传输接入。

## 曾考虑的替代方案

**创建内置 Agent 预设或用户预设。** 否决，因为它会组装另一个 Agent，把实时 IPython、目标和动态插件状态与独立实验拆开。

**替换通用 `ds` 命令和 3080 端口。** 否决，因为操作者仍需独立使用官方模式和其他预设。

**让 Web 独立进程读取持久会话日志。** 否决，因为会话日志不包含实时服务、内核对象、动态 fiber 或目标 activation，两个进程也不应把自己表现成同一个活动 Agent。

**隐藏“新建会话”并强制单实例浏览器。** 暂缓，因为这会改变 Web 产品行为，不只是给现有运行时增加传输入口。

## 结果

浏览器和终端交互观察同一个活动 Agent，重启回放仍由一份组合负责。端口和 rmux 归属清楚：`ds`/3080 是通用 Web，`dse`/3081 是自进化。源码启动依赖已构建的浏览器和客户端产物；干净检出第一次运行 `dse` 前先执行 `pnpm run build`。`surfaceContext` 已关闭，因此 Web 接入不会增加模型可见上下文。
