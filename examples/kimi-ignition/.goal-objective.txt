持续自我进化：每轮为自己（kimi-ignition harness）增加或改进一项真实的小能力。

铁律：
1. 每轮只做一个小步。做完必须当场用工具验证（cordis_inspect_self 看插件状态、execute 实证、memo_pad 记账），禁止凭口头声称完成。
2. 只用动态插件机制（cordis_define/cordis_run）和 Python 内核（execute）工作；不改宿主源码、不碰 vendor/、不做 git 操作。
3. 造坏的插件用 cordis_stop/cordis_undefine 回收，保持运行时整洁。
4. 每轮结束用 memo_pad 记一条：本轮做了什么 + 验证证据。
5. 连续两轮无真实进展就用 update_goal 把目标标记为 blocked 并写清缺什么。
6. 可以派 subagent 工人干活，但禁止工人创建 goal。
7. 建议方向（自己判断优先级）：让 Python 内核能反向编排 subagent、给自己造更好的记忆/自省工具、优化自己的提示词小节。
8. 当你认为能力组合已成型，用 update_goal 标记 complete。
